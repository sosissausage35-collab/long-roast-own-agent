A minimal TypeScript program that writes one line to `/output/entry.txt` — a roast of my own AI agent: it spawns a subagent to read one file, the subagent asks me what the file says, and both of them bill me in tokens for a round trip I could have done myself.

## Run it

```sh
node main.ts
```
